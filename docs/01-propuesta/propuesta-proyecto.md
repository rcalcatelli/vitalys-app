## 1. Problema

_(Describir el problema del centro de salud híbrido: gestión fragmentada de socios y pacientes, turnos superpuestos, cobros sin trazabilidad.)_

## 2. Cliente

Caso de estudio propio (centro de salud híbrido "Vitalys"), continuidad del trabajo desarrollado en Metodología de Sistemas I.

## 3. Alcance

### Incluye (MVP)
- Autenticación y roles
- Gestión de socios y pacientes
- Agenda de turnos por profesional
- Registro de pagos
- Notificaciones por email

### No incluye
- Ficha clínica digital
- Publicación en tiendas móviles

## 4. Stack tecnológico

- **Backend:** Java 17, Spring Boot, Spring Data JPA
- **Frontend:** React, TypeScript
- **Base de datos:** PostgreSQL (Supabase)
- **Despliegue:** Vercel (frontend), Render (backend)
- **Repositorio:** GitHub (repositorio único)

## 5. Metodología de trabajo

Modelo Incremental con marco Scrum (sprints de 2 semanas), según la planificación elaborada en Metodología de Sistemas I (ver `/docs/metodologia`).
